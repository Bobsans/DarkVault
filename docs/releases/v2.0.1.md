# DarkVault v2.0.1

This release improves token expiration controls and the administrator interface.
The server, CLI and all SDKs share version 2.0.1; HTTP/JWE remains protocol version 1.

## Token expiration

- Raise the maximum lifetime to one calendar year: the same UTC date and time
  next year, with February 29 clamped to February 28. The default remains 30 days.
  Stored explicit expiration dates are not extended.
- Combine presets and custom dates in one Expiration field. Presets cover 1 day,
  7, 30, 90 and 180 days, and 1 year, with the expiration date shown alongside.
- Add a styled calendar with local time selection, disabled out-of-range dates,
  validation before submission, and cancellation that preserves the current choice.

## Administrator interface and delivery

- Hide the type selector for recovery codes and keep secret clearing on Close.
- Fix Passkeys section placement and spacing, align secret entry fields, style
  dropdowns, and replace symbol icons with consistent SVG icons.
- Make browser layout checks wait for loaded data to avoid intermittent failures.
- Publish npm release archives using verified absolute paths.

See [the HTTP/JWE contract](../protocol.md) for token expiration semantics.
